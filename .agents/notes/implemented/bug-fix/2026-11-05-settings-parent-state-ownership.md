# Agent Note: 设置父页面的草稿与异步结果归属

Status: implemented

## Problem

设置父 Hook 同时持有系统配置、状态、提供商、LTR 文件和保存提示。刷新没有请求归属，较早的响应或错误可以覆盖较新的读取，旧 finally 还能提前取消当前加载状态。认证会话替换或离开页面后，旧保存会继续刷新配置、注册表或能力，并发布成功状态。

全局保存和提供商保存都在完成后重新读取配置，而读取统一清空全部编辑。保存期间新改的值会消失，保存一个模型也会清空尚未提交的其他设置。共享 saving 状态和 LTR busy 状态只在 render 后生效，同一 render 前的点击能重复请求。五秒保存提示计时器没有替换和卸载归属，会提前清除下一次失败。

提供商列表还显示重排序模型卡，但该对话框只有语言模型和向量模型的有效保存载荷。重排序卡打开表单并关闭后没有任何配置写入。设置索引每次普通状态更新都会重建 sectionIds，导致仍有效的 IntersectionObserver 被断开再创建。

## Decision

两个父 owner 保留原职责、所有默认与配置合并。每次系统／LTR 读取使用各自请求标记，结果只属于最新请求、仍挂载的页面 owner 和发起时的认证 revision。范围事件结束旧 owner，清空页面持有的旧配置、草稿、文件、提示和对话框，再发起当前范围读取。静默同账号重新登录也使旧结果失效；正常 token 轮换保留当前会话。

系统保存与提供商保存共享现有 saving 通道的同步标记。成功后读取服务器值，只从当前编辑对象中移除与提交时仍是同一节对象的草稿；后续编辑及其他未提交节保留。显式刷新也只清理它开始时的未变草稿。失败仍保留输入和真实 API 错误，不把读取或写入失败伪装为成功。空密钥、脱敏值、空路径、false、zero、DTO 字段及部分 PUT 规则保持。

LTR 注册与激活／回滚分别沿用原有 busy 通道。同步标记阻止 render 前重复动作，挂载／会话归属阻止过期提示、文件重置和后续读取；旧 finally 仅释放自己的标记。文件对、成功 reset key、失败保留文件及激活模型 ID 仍由原父逻辑持有，不跨入已完成的注册表组件。

保存提示的五秒计时器由父 Hook 创建、替换和清理，旧计时器不删除新消息。重排序模型卡使用现有页面失败反馈说明可在「RAG 配置」中选择重排服务与数量，不打开没有保存语义的对话框，也不创建不存在的凭证或 API。

页面按实际 visibleSections memo sectionIds，一个 effect 持有一个本地 observer。普通配置状态变化保留观察，权限造成可见节变化时按原顺序重新建立；索引滚动几何、原 JSX、class 和权限分区保持。

## Alternatives considered

- 保存后清空全部草稿并禁用所有输入，能简化提交清理，但会丢弃并行准备的配置或阻止正常编辑。因此只退休已提交且未再修改的节，不建立第二份配置状态。
- 只比较认证账号或查询参数，能阻止不同账号之间的部分覆盖，但同账号显式登录也会替换会话；读取又需要区分并发先后，因此复用现有 revision 并保留各请求标记。
- 抽出通用异步 manager 或新 Context 可以减少局部几行标记代码，但系统读取、配置写入、LTR 文件和列表拥有不同后果与 busy 通道。各动作顺序直接留在原函数，页面 owner 仅表达挂载／身份寿命。
- 为重排卡新造模型、密钥配置能使对话框看似可保存，但现有 Settings DTO 没有对应字段；真实用户入口使用已有 RAG 配置，明确指引即可。
- 给所有段落组件 remount 可以清理部分状态，但会丢失配置中的交互和文件选择，也不能结束旧后台请求，所以不以重挂载掩盖父归属问题。

## Consequences

页面维护少量局部请求标记，未来增加保存或刷新入口需要沿用相应通道；原 API 在途请求可能继续完成，已经接收的服务器写入不会回滚。提交退休按节对象身份判断，期间再次编辑同节即保留完整新草稿，避免通过值相等误删用户动作。没有新依赖、传输取消协议或通用控制器。

两个父完整源码及实际默认／权限／模型卡／对话框／文件／API／auth 消费链经读取。已完成设置节、ModelConfigDialog、共享 helper／API／DTO／store、组和 RBAC 页面不在本批修改或闭合。DOM 验证分别运行真实 Hook 和真实页面组合；页面叶子、权限／布局边界及网络受控，页面原父逻辑和共享 Input／observer 行为保留。初始 22 例中 18 个回归失败、4 个既有行为控制通过，后续当前成功／失败与载荷控制随报告记录。没有运行浏览器、服务、Python 或真实配置写入。
