# Agent Note: 可选追踪失败不阻断业务，取消只清理本地登记

Status: implemented

## Problem

LangGraph 两个真实节点使用同步 trace 上下文。网络提交已有日志隔离，但创建 LangSmith 客户端发生在该边界之外：构造失败会阻止业务进入上下文，并留下活动 span。BaseException 中断也绕过原来的 Exception 处理，造成登记残留。

## Decision

客户端创建与对应提交共用现有错误处理入口，继续按原日志级别报告遥测失败。业务结果由原业务执行产生，不构造备用结果或伪造提交成功。

普通成功与业务异常继续按原策略结束和提交 span。BaseException 中断只移除本地活动登记，原对象继续抛出；不为取消增加 SDK 结束调用、网络清理、重试或等待。没有宣称远端运行记录已经关闭。

## Alternatives considered

对所有退出都调用 end_span 可以统一代码，但取消时会新增遥测工作，其时延依赖真实 SDK。只捕获普通 Exception 不能清掉中断登记，因此单独保留一个本地清理分支。

## Consequences

可选客户端初始化失败不再阻止主流程；缓存客户端、环境设置、提交参数和正常异常处理保持。真正的状态类、普通包和已挂载 trace 上下文继续存在，无调用的装饰器、反馈／链接便利接口及异步上下文退出。

原四个选源代表与中间四例分别保留；最终取消代表单独验证原异常身份、本地零残留和没有新增结束调用，其他语句以完整 AST 对照承接。只使用受控 SDK、时钟和日志端口，没有执行真实 SDK、网络、事件循环、锁线程或应用测试。
