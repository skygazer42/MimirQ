# Agent Note: 共享查询 Hook 的异步结果归属

Status: implemented

## Problem

身份范围变化后，QueryProvider 会清除旧查询，但 useAuth 的查询函数仍可能在迟到的 profile 响应中写入旧用户。旧 token 的 401 也会让 Hook 清除已经替换或刷新的 token，绕过 API 层已有的请求凭证匹配保护。

索引修复的局部状态没有完整绑定选中的文档。原来的重置依赖只区分是否选中一个文档，因此同一数据集内从文档 A 切到 B 不会停止旧操作；修复提交返回后才建立轮询 generation，也允许较早的 POST 最后返回并接管较新的状态。

连接器的取消、重试和续跑完成后，会调用同时改变显示范围的列表加载函数。在数据集 A 发起动作、切换并加载 B 后，A 的迟到结果会把列表重新切回 A。

## Decision

本文关于连接器显式读取复用新鲜缓存的策略由[前端显式刷新与请求结果归属](2026-11-12-frontend-request-results.md)部分替代；下文保留原取舍，身份与操作结果归属仍有效。

React Query 继续持有远程查询数据，auth-storage 继续持有当前身份。useAuth 在 profile 请求完成时检查现有查询的 cancellation signal；已经取消的查询不写入旧 profile，也不处理旧错误。401 只清除仍与该请求 token 相同的凭证。成功响应不按 token 文本是否变化来拒绝，因此同一逻辑查询中的正常 OIDC 刷新仍能保存返回的 profile。

useIndexAudit 为每次数据集／单文档选择持有局部身份，并在发出 POST 之前建立 generation 和 AbortController。提交、轮询及错误处理只发布当前身份、当前 generation 的状态；离开后返回相同文档也属于新的访问。finally 只释放该操作仍持有的 controller，旧操作不能清除后续操作的资源。现有 GET signal、查询 key、缓存策略、轮询次数和提示文案保持。

连接器列表的两条相同读取路径复用一个私有普通函数。显式列表加载继续设置显示范围；动作完成仅通过私有缓存读取回调刷新发起时的数据集，保留原查询 key、fetchQuery 缓存策略和读取失败警告。API／DTO 类型直接引用既有所有者，原始 JSON 的兼容字段、数组判断和缺省处理仍留在原边界。

## Alternatives considered

- 对所有 profile 成功响应都比较请求前后的 token，写法直接，也能拦住部分身份切换。但 API 层会在同一查询中正常刷新 token；这种判断会丢弃合法的刷新结果，因此使用既有查询取消信号区分失效查询，只在 401 时匹配请求凭证。
- 保留提交后的 generation，仅保护轮询，能减少对提交链的改动。但迟到的 POST 本身就会发布消息、启动轮询并取代新状态，不能解决已复现的顺序问题，因此归属在提交前建立。
- 为身份或文档变化改写全局查询 key，能让更多隔离进入缓存层，但会改变已有缓存／调用契约。当前缺陷是局部异步副作用越界，因此沿用 QueryProvider 和现有 key，只收紧副作用的发布范围。
- 在连接器动作完成时跳过旧数据集的刷新，可以阻止列表跳转，但会放弃原有缓存更新。把缓存读取与列表选择分开后，旧数据集仍按既有缓存策略读取，当前选择也能保留，无须新增 generation 或全局失效规则。

## Consequences

当前请求的 401、500、索引修复失败和超时仍按原策略呈现。取消与替换只阻止旧前端结果发布；已经提交的后端修复任务不会因此回滚，重新读取仍由既有 API 负责。如果未来 POST API 提供取消能力，可以补充传输清理，但结果归属检查仍有必要。

连接器缓存读取与显示范围现在有两个明确入口，维护者需按调用意图选择。动作完成仍使用原来的 fetchQuery 策略：缓存未过期时可能直接复用，不引入强制刷新。取消、重试和续跑的回归测试让 A 缓存过期，既验证 A 更新，也验证 B 保持可见。

身份与索引测试在原生产实现上出现 9 个回归失败、6 个通过；连接器另外 3 个场景也按预期复现。修复后两组真实 Hook 用例 18 个通过。涉及 auth、租户访问、QueryProvider、OIDC、分页、索引 API 和实际消费者的最终检查与命令记录在本批报告中。未启动服务、浏览器或 Python 测试。

按 useAuth、useIndexAudit、useConnectorRuns、React Query、auth-scope、QueryProvider、索引修复和连接器缓存范围检索活跃笔记，没有发现同一决定的旧记录；既有笔记不被替代。本记录说明当前实现与限制，独立审查和中央覆盖状态由控制者维护。
