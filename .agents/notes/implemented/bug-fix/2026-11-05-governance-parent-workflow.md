# Agent Note: 治理工作台的重置意图与文档同步

Status: implemented

## Problem

工作台在分类或标注之后允许全局重置，此时原文和清洗草稿可以完全相同。全局重置仅更新文本和元数据，清洗工具无法察觉同文本重置；正在等待的规则结果会继续进入 LLM 阶段并写回已经放弃的草稿。质量检查同步新的分数与问题数组，却没有同时结束原扫描，旧结果仍能恢复已清空的分数和问题。

远程文档同步只读取解析工作区和知识库各自的前 200 条，超过第一页的文件无法进入工作台。后端实际存在的 cancelled、quarantined、deleting 状态以及未知状态，又被默认映射成解析成功。文件名搜索框没有连接任何过滤逻辑。

保存修改后的 Markdown 时，父面板只在原文字段缺失时携带原文。共享存储的内容缓存写入需要完整的草稿／原文对，因此原文已经存在的文件反而会向缓存写入空原文。上传取消在 preview 阶段有归属检查，但 ZIP 解压完成到创建目录之间缺少检查，取消后仍会创建目录并提示成功。

## Decision

`data-governance-panel.tsx` 继续拥有文件治理草稿和全局重置意图。每个文件的本地治理状态保存 `resetRevision`，全局重置递增该值；质量检查与清洗组件通过可选同名 prop 将它接入已有请求失效 effect。文件 key 仍只表示文件访问，回调身份仍只更新通知引用。重置结束当前请求与预览，但不重建组件，也不清除格式、LLM 开关、提示词、管线配置、后端扫描开关等工具偏好。分类和标注仍消费全局重置产生的新元数据数组。

同步查询分别读取两个 API 的完整分页，保留每页 200 条、首响应 total 和空页停止条件。后续页开始前检查 QueryClient signal，卸载或查询失效后不再发下一页；已有 API 的在途 HTTP 仍可能完成。两个来源继续独立结算，一个来源失败时保留另一个来源及现有本地文件。同步合并仍保留本地草稿、原文、目录和治理／切块状态，不扩展共享存储或 API。

处理状态只在已知成功别名上投影为 parsed；processing 等进行中别名仍是 parsing，failed、cancelled、quarantined 等失败终态为 error，其余值为 pending。这个四态投影消费现有共享存储类型，不把发布状态 publication_status 与处理状态混在一起。文件名搜索按裁剪后的大小写无关子串匹配，与现有数据集和目录后代过滤共同计算当前可见文件。

父面板保存正文变更时，同时传入当前原文，满足现有内容缓存成对写入契约；只改变切块状态时仍不触发正文持久化。ZIP 解压成功或失败返回后先核对原上传 controller，只有当前操作可以创建目录、发布提示或继续 preview。

## Alternatives considered

- 只依赖文本变化和新元数据数组，不需要增加 prop，也能覆盖通常的编辑。但真实全局重置可以保持文本、零分和空结果不变，清洗和扫描无法据此识别放弃意图，因此显式传递重置 revision。
- 将 revision 加入所有工具的 React key，可以复用卸载清理。但全局重置会连带清除工具格式、LLM、提示词等本地设置，因此保留实例，只使现有操作失效。
- 保持单页同步能限制请求数和首次列表大小。但界面没有下一页入口，后端 total 已明确表明还有文件，因此按现有分页契约读取完整集合，不引入新的列表管理器。
- 在共享存储里推断缺省原文，可以统一替调用方补字段。但那会改变其他调用方的缓存语义；本批父面板已经持有准确原文，直接完成自己的载荷即可。

## Consequences

同文本重置可以结束旧工作，后续操作仍按原忙碌状态与结果发布规则运行。每个文件多一个本地整数，两个工具多一个可选输入；未来增加全局丢弃入口时，需要显式传递同一意图，不能把普通回调重建当作重置。全量分页增加大库下的读取量，远程总数或排序在读取期间变化时不提供事务快照保证。

父面板完整源码和上传、缓存加载、过滤、选择、编辑、保存、重置、提交路径经复核；工具仅做必要重置契约迁移，不重复宣称关闭其他依赖。界面结构、样式、提供方、工具预算、API 方法、数据集路由及现有本地元数据寿命保持。已经接收的后端写入不会因前端重置或取消而回滚。

真实父面板、四个工具、QueryClient、PipelineOptionsProvider、Zustand、WorkbenchScaffold 和 Select 的 DOM 测试保留，只控制网络、内容缓存、翻译、Markdown 展示和外部配置面板边界。修改前 20 个场景中 11 个回归失败、9 个现有策略控制通过；同文本规则／LLM、扫描、第二页、状态映射、原文缓存、搜索与 ZIP 取消均有实际失败证据。没有运行浏览器、服务、Python 或真实网络，不声明布局、渲染帧或后台事务已验证。

活跃笔记检索命中[治理工具的请求归属与原文坐标](2026-11-04-governance-tool-request-ownership.md)，其文件访问和请求标记决定继续成立，本记录补充父面板的显式重置入口。另有[文档 Hook 的查询归属与轮询生命周期](2026-11-04-document-hook-query-ownership.md)持有另一套文档查询 Hook；本面板保留自己的两个来源同步，不吸收或修改该决定。没有需要拒绝或归档的同一父工作流提案。
