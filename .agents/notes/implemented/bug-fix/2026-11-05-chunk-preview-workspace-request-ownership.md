# Agent Note: 切块工作台按文件、范围与登录会话接收异步结果

Status: implemented

## Problem

工作台在取消预览、清空文件、切换文档或数据集后仍接收旧响应。名称、大小和修改时间相同的两个真实 File 还会命中同一个本地缓存。自动预览取消后立即重启；登录更换没有清除文件、历史和子面板状态，模块级范围加载 Promise 也只按数据集去重。

设置读写 effect 的先后顺序不足以抵御 StrictMode 重放。分隔符、父子切块、性能与数据集偏好会被初始值覆盖，初始空列表还会删除焦点。先从不完整的解析缓存装入文件时，也会过早放弃尚未由后端补齐的已保存焦点。

入库按钮的 disabled 状态不能阻止同一事件批次内两次 Ctrl+S，单文件和批量动作也没有共用提交锁。旧文件的完成会改写新文件标题、成功状态和提示。预设保存、插件黄金集导入有同样的同步重复提交问题；预设列表、保存草稿、配置读取、调优、审计与插件报告缺少各自的结果归属。

## Decision

保留同一个 ChunkPreviewContext，在现有 Provider 外层订阅真实认证范围，并以范围作为工作区组件的 key。更换身份会卸载原工作区及其子面板。每个异步动作还直接捕获并检查 getAuthSessionRevision；同用户显式重新登录会使旧动作失效，普通 token 刷新不撤销原动作。范围文件去重 key 包含认证范围、会话修订和数据集，仍保留同会话 StrictMode 去重与每次八份文档上限。

预览沿用请求计数器和 AbortController，所有退休入口使旧成功、错误和上传回退失效。恢复缓存也会退休正在运行的网络预览。本地 key 加入实际文件队列项身份；已显示 SHA 的复用同时要求原 File 与原会话。自动预览记录已尝试的配置 key，取消保留用户开关，后续文件／设置动作仍可触发新尝试。

偏好写回等待读取完成状态进入下一次 render；焦点在文件初始化后恢复，保存目标尚未加载时等待范围同步。自动和批量请求共用原有参数构造函数。调优与历史恢复显式传入大小、重叠、策略和解析器的请求快照，使缓存 key、参数校验、API 参数和历史描述使用同一组值。

单文件和批量入库共用同步提交引用，旧 finally 只能释放自己的锁。文件队列完成与当前文件界面发布分别校验；切换视图后，仍存在的原文件可以变更队列状态，但旧结果不能改写新文档标题、草稿或提示。直接调用的业务异步函数保留原 API 参数、状态轮询间隔、三十分钟预算、特殊处理中错误和批量处理顺序。

有效同会话写入在离开界面后仍完成原缓存义务。文档入库捕获实际 documents/list Query，黄金集导入和回归捕获实际 regressionCases、regressionRuns 与 regressionLeaderboard Query；只有未被移除或重建的原 Query 才失效，其他数据集与替换 DTO 保持原样。离开视图只退休界面发布。已授权的黄金集导入并回归继续完成原操作；登录会话更换则禁止后续请求。没有创建不存在的缓存、拼接 DTO 或撤销已经接受的后端写入。

预设列表只发布最新请求，刷新使用函数式更新保留当前选择。预设创建完成可以刷新当前范围的列表，但不能关闭或选择已被用户改写的新草稿。配置 File.text 与剪贴板读取共用直接导入函数。调优、审计与插件报告使用各自原文件／选择及会话边界，没有通用请求 manager 或新增 Context。

## Alternatives considered

仅检查 mounted 无法区别同一个组件里的两次文件访问，也不能处理同用户无范围事件的新登录。只调用 abort 无法阻止忽略 signal 的成功响应或旧 SHA 回退。只用 React 的 loading／saving 状态不能阻止同步重复事件，因此分别保留业务请求身份和同步提交引用。

把所有完成都放到 mounted 检查之后会漏掉已经成功的持久化写入。缓存完成按真实 Query 对象身份与原会话判断，队列和提示另按视图判断。没有把缓存移除当作撤销私有 File 写入的授权，也没有合并不同列表响应的 DTO。

使用统一操作框架会掩盖预览、文件读取、调优、预设和持久化写入的不同生命周期。现有组件内的直接函数已经能表达这些规则，故没有引入通用封装、额外重试、兼容 facade 或新的状态所有者。

## Consequences

真实 React DOM 用例通过实际 Ctrl+S、组件按钮、配置输入、目录拖放与认证存储入口覆盖这些时序。工作台五十项行为用例使用最终测试字节回放原实现，四十项失败、十项对照通过；修复后五十项通过。原文与 Monaco 的十二项独立用例另行保留。完整目录八个测试文件共七十八项通过。

目录扫描继续读取到空批次，嵌套目录顺序与扫描错误传播保持；失败扫描不提交部分结果。只审核元数据或切换禁用状态保留后端 token 估计，真实内容编辑仍使用原前端估计。复制 cURL 对所有中间行统一添加一个续行符，并正确转义自定义分隔符中的单引号；没有执行生成的命令或访问网络。

测试替换 HTTP、重型 SDK／渲染器、弹窗与选择器适配层；文件、React 状态、队列、认证修订和 QueryClient 使用真实实现。没有启动浏览器、服务器、后台任务或真实 Monaco。界面 JSX、样式字面量及只读所有者另有静态校验，不据此声称实际浏览器布局或后端行为已验证。
