# Agent Note: 集成设置保留原始绑定与数值输入

Status: implemented

## Problem

Dify 绑定既支持字符串／列表，也支持包含 dataset_ids、datasets 或 dataset_id 的对象。对象还能持有 query_routes、strict_query_routes、继承来源与插件规则。设置区只解析出数据集 ID 再重建整个 JSON，因此新增无关绑定或删除一条绑定也会丢失已有路由和其他配置；修改对象绑定的数据集会把整条对象替换成数组。合法 JSON 的非对象根值又被当作空配置显示。

四个集成区的整数输入用 parseInt 读取值，浏览器能够解析的 1e2 因而变成 1；带小数的值也在到达原 API 校验前被截断。Dify 接入地址复制在剪贴板拒绝时留下未处理的事件 Promise，能力缺失时却显示成功图标，提示计时器也没有随区块卸载清理。

## Decision

Dify owner 保存并写回原始 JSON 对象，仅在显示标签时递归投影数据集 ID。修改一条已有对象绑定时，沿用后端按 dataset_ids、datasets、dataset_id 顺序识别的首个现有字段，只替换其数据集选择并保留其余字段；新绑定继续写数组。其他绑定的键、字符串／列表／对象形式和未知字段原样保留。删除最后一条绑定仍写空串。

根值必须是 JSON 对象，语法或根形状错误均显示现有警告。明确点击生成绑定来覆盖损坏配置的原有恢复含义保留，不增加全局设置校验入口或隐藏修复。

数值控件用 Number 读取完整输入字符串，现有空串默认、零值默认和 min/max 表达式不变。合法指数值进入正确的数字；小数不再被悄悄截成整数，仍由原后端整数 DTO 校验并由父设置保存流程显示失败。URL 超时原本支持的小数解析继续保留，不借此迁移其他输入规则。

复制操作显式检测剪贴板能力并处理拒绝，当前区块显示原错误；完成结果只属于发起时仍挂载的 owner。重复成功复制替换原提示计时器，卸载使 owner 失效并清理计时器。生命周期由挂载持有，不以父 update callback 的函数引用作为身份。数据集读取仍沿用现有穷尽列表 API 和取消发布判断。

## Alternatives considered

- 继续把所有绑定标准化成数据集数组，便于渲染与去重，但会删除后端实际消费的路由和插件配置，因此将原始写回与显示投影分开。
- 把每条旧绑定都改成统一 dataset_ids 对象，格式更整齐，但会重写未编辑项及旧别名，扩大持久化变更范围，因此只更新当前绑定已使用的首个选择字段。
- 使用 valueAsNumber 也能读取指数值，但空输入返回 NaN，需要重做当前默认分支；Number 加原字符串默认保留现有空／零语义，改动落在原控件处理函数内。
- 新建通用数字表单或异步操作管理器可以统一全页，但当前缺陷只需要原 owner 的数值转换与一个复制资源生命周期，因此不新增共享框架，也不迁移父保存 Hook。

## Consequences

高级 Dify 路由不会因无关编辑消失，数字输入不再按字符串前缀写入。所有四个 owner 完整复核；公共 props、字段名、默认值、样式类、开关确认、权限分区和 API 路径保持。脱敏字符串及空密钥仍按既有服务端规则保留真实凭证，空服务地址／模型目录等字段继续保持各自含义。

校验使用真实 React DOM、原 Input／Switch／Radix 确认组件，并在数据集 API 和剪贴板边界提供替身。原实现复现绑定丢失、非对象静默、复制失败与数值截断；原有空值、密钥和高风险开关确认有对照。happy-dom 的 badInput 正则不接受指数语法，数值验证因此核对控件的 valueAsNumber 与实际 patch，不将模拟器的 validity 作为浏览器验收。

未运行浏览器、服务、Python、数据库或真实剪贴板权限请求。父页面、保存 Hook、API／DTO／配置及 primitives 只读取相关契约，不作为完整 owner 关闭。活跃笔记只命中相邻的后端[Dify 纯规则归属](../simplification/2026-11-04-dify-helper-ownership.md)；其决定独立，本记录不修改或吸收该决定。
