# Agent Note: 邻接窗口为零时仍执行独立的同文档扩展

Status: implemented

## Problem

上下文扩展入口明确允许邻接窗口为零且启用短文档扩展，但随后因邻接索引集合为空直接返回，同文档扩展永远没有执行。原源码的有效文档锚点代表确认加载和扩展端口都没有被调用。

## Decision

空邻接集合只在没有可用同文档扩展范围时提前返回。启用开关、正的短文档阈值和有效文档锚点共同决定该范围。已有加载函数、租户与文档查询、活动管线过滤、资源关闭、扩展预算、评分与排序保持。

## Alternatives considered

把邻接窗口从零提升为一能进入加载，但会改变明确关闭邻接扩展的配置。删除全部提前返回则会为没有有效范围的请求创建 Session。保留零窗口，修正提前返回的条件。

## Consequences

单独启用短文档扩展现在能够到达原有实现，因此该配置可能实际读取分块；没有有效范围时仍直接返回。加载失败沿原可观察降级处理，没有新增数据来源或权限放行。

原失败证据冻结，修后另核零窗口、关闭开关、零阈值、无文档锚点、正常窗口、加载失败与零预算。只执行选取的源函数和受控端口，没有运行真实 Session、SQL、检索、模型或应用测试；不将这些代表称为生产集成验收。
