# Agent Note: 组织实体与统一后的大小写比较

Status: implemented

## Problem

启发式实体分类先将名称 upper，再与混合大小写的组织名称集合比较。IETF 能匹配，Mozilla、Fastly、OpenAI、Alibaba 和 DashScope 却全部落到 concept，实际提取链会保留这个错误类型。

## Decision

组织集合中的五个名称使用同一大写形式。标准、组织、协议和软件的判定次序、正则、其余类型规则和提取限额保持，不借此改软件品牌或通用大小写策略。

## Alternatives considered

修改所有实体的大小写或候选抽取正则会扩大影响，特别是软件名称已有独立规则。只修组织集合与现有比较值的一致性。

## Consequences

后续提取能将这五个已列出的品牌归为 organization。历史实体数据没有执行迁移，也没有把类型修复说成整体知识图谱结果已验收。

原六个品牌分类观察独立保留，修后用固定正则端口核对这一决策及其余分支的源码保持；没有运行真实正则资源、模型、数据库或应用测试。
