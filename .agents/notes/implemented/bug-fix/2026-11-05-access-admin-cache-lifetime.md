# Agent Note: 页面退出后的访问管理缓存完成职责

Status: implemented

## Problem

访问管理写操作把挂载、认证 revision 和原 Query 实体一起作为全部成功副作用的条件。组 A 保存期间切到 B 后，A 组件结束，但真实 QueryProvider 仍保留 A 的缓存：staleTime 为 10000 毫秒，gcTime 为 900000 毫秒。已经成功的服务器写入没有更新或失效原缓存，十秒内返回 A 仍显示旧组名。

组列表创建／删除、租户成员角色保存／移除也出现退出页面后的旧缓存。成员添加／移除另有原基线的 latest-key 缺口。恢复旧回调直接写响应又会使迟到的旧 payload 覆盖新访问已经取得的值，并触发旧提示或清理当前草稿。

## Decision

每个业务 async 函数分别核对缓存资格和视图发布资格。缓存资格继续要求发起时的认证 revision 有效、原 Query 对象仍是当前缓存中的同一实体；挂载状态只决定原视图能否接收提示、草稿、对话框和直接数据更新。原会话或原实体已退休时，所有完成副作用仍停止，不创建替代 Query、不写入新会话数据。

视图已退出但缓存资格仍有效时，成功写入只使受影响的现有缓存失效，活动观察者通过原 queryFn 读取服务器当前值。旧响应 payload 不再写进新的访问；新访问的草稿和已经完成的服务器读取保留。失败提示仍要求当前视图与缓存资格同时成立。同步锁、finally、提交草稿退休和原 API 载荷保持。

组信息保存只选择原详情 Query 和真实组列表类型。组列表既有页面的 limit=500，也有 GroupChipsInput 的 limit=1000，失效匹配使用现有 queryKeys.groups.list 的类型段；B 的详情和成员 Query 不匹配。列表创建刷新这些列表；列表删除另用目标组的精确详情前缀刷新其相关缓存。成员添加／移除及 RBAC 写入在退出视图后只失效原 Query 实体。没有 queryKeys.groups.all 的无条件跨组失效。

原新动作仍在开始时使用 QueryCache.build，因此空闲清除后可以恢复操作。已经在途的请求继续持有原实体，clear／重建后不能用相同 key 恢复旧资格。没有新缓存 key、TTL、传输取消协议、manager、Context 或后台授权策略。

## Alternatives considered

- 卸载后丢弃全部完成结果可以避免旧 UI 发布，但缓存的寿命长于组件，会保留仍被视为 fresh 的旧服务器值。因此保留独立的原缓存完成职责。
- 退出视图后直接 setQueryData 旧响应，可以立即显示本次写入，却可能回退新访问已经取得的更新结果。因此只失效有效实体，经服务器当前值重新读取。
- 无条件失效 groups.all 能刷新列表，但也会刷新当前 B 的详情和成员、扰动其忙碌状态。因此只匹配原实体、真实列表类型或实际删除目标的前缀。
- 每个视图建立独立 key 或通用异步 manager，能隔离部分回调，却增加重复请求与状态层。因此保留现有缓存和直接可读的各业务函数。

## Consequences

退出视图的成功写入可能触发受影响的当前观察者重新读取；缓存数据在读取前仍保留原快照，并已标记失效。已经被后端接受的写入不会因前端退出而回滚。新请求入口需要同时考虑业务缓存与视图的实际寿命。

十二个真实 QueryProvider／QueryClient 与控件探针固定了两个精确基线：ea0 中 10 失败、2 个保护控制通过；f37 中 7 通过、5 失败。七个是严格 f37 通过／ea0 失败的缓存回归，两项成员原缓存缺口在两版均存在；新 A 草稿与服务器真值的复合控制分别暴露两版不同缺口。旧 payload 与 B 的缓存对象、读取次数、草稿和提示控制防止恢复旧覆盖方式。原有 36 个控制与新探针一起验证；类型、lint、格式与源码契约证据随增量交付保留。

本决定进一步约束[原访问管理操作归属](2026-11-05-access-admin-operation-ownership.md)中的缓存完成部分，原同步互斥、草稿和身份决定继续成立。[认证会话归属](2026-11-04-auth-refresh-session-ownership.md)和[算法设置操作归属](2026-11-05-algorithm-settings-operation-contracts.md)继续持有各自原接口，不被替代或重新闭合。新笔记审计未发现需删除或归档的提案；API、DTO、auth、共享 selector、已闭合消费者和后端只作相关契约读取。浏览器、服务器、Python、后端 SDK、数据库与真实授权未执行。
