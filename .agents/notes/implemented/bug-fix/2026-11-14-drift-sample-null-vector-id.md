# Agent Note: 漂移采样识别未生成向量的分块

Status: implemented

## Problem

索引在关闭向量写入时返回并保存 None，DocumentChunk.vector_id 也允许为空。漂移查询没有排除这些行，采样函数却直接调用 strip，合法的无向量分块会触发 AttributeError。

## Decision

采样在读取向量 ID 时跳过 None，然后保留原来的空字符串和空内容筛选。查询仍返回固定三列，直接解包，不猜测额外的行形状，也不把任意对象转换成字符串。有效样本的内容裁剪、空间计数、存储向量读取、重算与距离统计保持。

## Alternatives considered

把非字符串 ID 全部跳过可以避免更多异常，但实际生产契约只有字符串或 None，扩大容忍范围会隐藏坏数据。把条件挪进 SQL 会改变既有排序后限额的样本窗口，因此仅在原采样边界处理。

## Consequences

无向量行不再终止本次监控。它仍占原查询限额的位置，不额外补抽样本，也没有扩大数据库范围。无效内部类型继续暴露。

原源码的 None 失败单独保留。8 个公共入口代表覆盖有效、缺失、混合向量 ID、零预算、缺存储向量和零范数；独立代表另核混合行的裁剪和计数。所有外部模型、向量存储和查询都是受控端口，没有运行真实模型、数据库、SDK 或应用测试。
