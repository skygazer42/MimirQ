# Agent Note: 浏览器正文缓存保留局部更新与已应用补丁

Status: implemented

## Problem

解析文件的局部更新把未提供的正文或原文补成空串，再交给完整替换缓存接口。只修改一种内容会清空另一种内容。旧更新的版本检查只约束内存结果，已经开始的缓存事务仍可能提交。

取消全部旧写入也会丢数据：后台更新已经应用到内存并正常返回，随后改目录或原文，却中止其尚未完成的正文写入。若一个等待完成的更新接管这份内容，第三个操作还可能把继承的已应用补丁一起取消。元数据存储异常原先也会被正文缓存的 catch 捕获，导致重复应用和错误的降级日志。

## Decision

[缓存公开能力与接收边界](2026-11-14-cache-public-contracts.md)部分接管原预览完整替换入口：实际预取/查看器只填缺失缓存；本篇的确认型完整/局部更新、接管、取消和已应用补丁责任保持。

完整替换与局部更新保留各自合同。updateDocContentInCache 接收明确的文件身份和可省略的 Markdown 字段，在同一 readwrite 事务中读取、合并和写入；省略表示保留缓存中的对应字段，显式空串表示清空。不存在的记录沿用当前缓存格式的空正文表示，普通更新不从空的元数据占位值补造另一种正文。

每个身份范围和文件只登记一个未完成更新，持有原生 AbortController、当前内容、已应用内容和当前内容是否已应用。新任务取消被接管事务，并继承已经应用的补丁。元数据操作的取消范围由[解析编辑与移交](2026-11-14-parsing-editor-handoff.md)进一步收窄：独立目录/解析器变化保留待写正文，真正的任务状态、来源和阶段更替才取消尚未应用内容，继承补丁的持久化责任保持。删除、清空和身份切换取消整份任务，不恢复其内容。任务结束只清理仍属于自己的登记。

缓存事务监听当前 signal，结束时移除监听并关闭连接。事务启动、请求工厂和复合事件回调的真实异常向调用方报告；写入等待事务完成。取消后的空结果属于现有失效合同，不表示保存成功。IndexedDB 的 open 本身没有本项目可用的原生中止入口，取消会阻止它返回后再开始事务，不增加超时或另一套取消协议。

解析完成的可选内存模式继续存在；确认型保存、即时重试和治理页面预写正文的当前决定由[本地文档保存确认](2026-11-13-browser-document-save.md)接管。原先保留的三次无分类即时尝试退出，显式保存由 Store 确认正文与索引；可选缓存与真实元数据失败仍按各自边界处理。本篇同事务局部合并及接管/取消的独立决定保持。

## Alternatives considered

- 继续使用完整 put，调用点较少，但给未提供字段填空串会删除另一份正文，无法满足局部更新合同。
- 先在独立读取 Promise 中取旧记录，再开启另一事务保存，异步步骤较直观，但两次操作之间可能已有其他写入，不能保证合并与提交基于同一事务。
- 每次新操作都取消旧事务，任务状态最少，但已应用内容仍有落盘责任；两步与三步复现均出现内存新、缓存旧。单独保存已应用补丁后才能正确接管，不按字段叠加版本计数。

## Consequences

局部更新不再覆盖未指定内容，连续操作也不会丢失已经应用的清空或编辑。代价是每个未完成文件更新需要明确区分当前内容和继承的已应用补丁；这些字段只用于当前真实生命周期，未成为新的持久化格式或公共状态层。

四个相关文件的 60 项测试通过，覆盖局部字段、清空、取消、请求启动失败、两步及连续接管、空更新、配额异常和身份隔离；相应修复前失败日志保留。独立只读复核对接管链、删除、清空和身份切换重新读取缓存，未发现该范围内剩余问题。Edge 从治理页编辑并保存，读取原生 IndexedDB，再刷新分别查看正文与原文；HTTP 使用已有隔离 fixture。

固定 MDN 源码合同、写法范围、逐声明命名和验证日志位于 .frontend-structure/20261112-full-frontend-guidelines/cache-writes/。这不等于整个缓存模块或前端已经达标。merge 前的读取失败及真实写入前置条件由[恢复记录](2026-11-12-browser-store-restoration.md)和 storage-read 切片持有；正文缓存的既有内存模式直接记录原始错误，退出只用于选择两句警告文案的分类函数。

本决定接管[浏览器 Store 恢复记录](2026-11-12-browser-store-restoration.md)之外的正文写入职责，恢复入口只读取数据字段的决定继续有效。活跃笔记中的查询归属与服务端请求记录不持有本地正文的原子合并合同，没有因此退出的旧笔记。
