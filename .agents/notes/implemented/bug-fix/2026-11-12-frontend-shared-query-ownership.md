# Agent Note: 前端查询形状、目录投影与私有任务归属

Status: implemented

## Problem

聊天详情、评测限量消息与历史无限分页原先共用同一消息键。详情包含 messages，无限查询包含 pages/pageParams；新鲜缓存可在页面切换时把另一种结构交给调用方。当前 TanStack 依赖的内存复现确认分页观察者会报错，详情读取也会取到不存在的 messages。

多个页面用不同用途键读取完全相同的完整目录。用量、治理和解析又把名称投影存进各自查询；解析读取失败返回空数组，共享选择器忽略 error，操作者无法区分故障与真实空目录。共享后，关闭的生成弹窗仍能收到目录错误，因此错误消费也需要属于当前可见表单。

全局任务中心位于私有页面身份边界外。操作完成可在账号变化后继续反馈；仅清理忙碌状态还不能退休空闲观察者保留的旧 data。长请求编号还会撑大错误提示的最小内容宽度，把移动端重试按钮挤出弹窗。

## Decision

消息缓存按实际结果形状区分：详情使用 messages 并包含真实 limit/before 参数，历史无限分页使用 messagePages。页面直接消费已有 ConversationDetail；请求和恢复回调转发现有 ApiRequestOptions.signal，不通过额外包装丢掉第三个参数。

相同输入的完整目录使用 queryKeys.datasets.exhaustive()，缓存保存原始 Dataset[]。名称字典与 id/name 选项由原生 select 投影给观察者，原启用条件与新鲜度选择继续由各调用方持有。目录 API 每页转发同一 signal，必需 items/id 按实际响应模型读取。分页大小、重复页终止和已测试的非可信 total 提示政策继续保留。

当前查询错误在选择器、治理范围控件和解析工作台中反馈；缓存数据仍可使用。重试以原生 isFetching 禁用重复触发；生成弹窗只在打开时消费属于当前来源的错误。错误提示采用当前 Tailwind 的 wrap-anywhere，使长编号参与真实最小内容尺寸计算，按钮保留自身宽度；不裁掉请求编号来掩盖布局问题。

TaskCenter 进入已有 AuthGuard 的 keyed children，身份事件结束旧观察者与组件访问；认证页既有输入保留规则继续有效。取消和重试共用一个局部操作函数。唯一操作引用与既有认证修订号约束结果发布，布尔 isActing 表达本地操作阶段并禁用两个入口；旧 finally 不释放后续操作。

CommandMenu 同样位于已有身份边界内，认证事件关闭全局打开状态并清理连续按键。文档、数据集和会话搜索缓存保留完整列表封套，菜单只通过 select 消费 items；服务端已筛选的结果关闭 cmdk 二次过滤，失败提示与正常空结果分开，刷新失败时保留可用缓存。Conversation 的标题、最近消息和时间明确允许后端实际返回的 null，字符串守卫在进入 cmdk 前排除空字段。

没有处理方的批量重试、批量暂停命令退出。预检与报告命令先导航数据集列表，说明选择数据集后进入文档预检；真实扫描、查看及导出由 /datasets/[id]/precheck 持有。旧入库页的跨组件导出事件退出，不把执行监控冒充报告页，也不为保留一个命令另建批量工作流。旧 page-client 的其他职责仍在全量待审范围内。

没有生产调用方的数字动画 Hook、平板和桌面转发 Hook 退出。ResizeObserver 的待提交测量直接来自初次 DOMRect；只有安排测量后才有帧回调，替换和卸载取消所属帧，因此不再维护不可能的空测量分支。

解析与治理工作台的完整两来源目录及本地工作副本合并另见[文档库按来源和读取起点同步](2026-11-13-document-library-reconciliation.md)。其带起始引用的同步结果不是本篇其他目录选择器的同义可写副本，两个范围分别核验。

## Alternatives considered

- 为每个页面保留用途键能隔离各自请求状态，但相同输入与原始结果重复保存在多处。共享 Query 仍允许观察者各自控制启用和新鲜度；实际不同结果形状的消息查询则继续分开。
- 把名称投影直接放进共享 queryFn，调用处较短，但会让其他目录消费者收到字典或字段子集。select 只改变观察者结果，原始缓存保持 Dataset[]。
- 每个 Hook 自建 AbortController，取消意图直接，但会重复原生查询的资源所有权。已有 signal 足够，恢复过程保留其真实调用者拥有的控制器。
- 只在任务操作完成时比较认证修订号，可以阻止迟到提示，却不能退休空闲观察者。复用现有私有页面身份边界同时结束读取与操作访问，免去另建身份状态容器。
- 为全局命令补建批量任务流程可以让原入口执行，但需要新的范围选择、权限及失败政策。当前没有这些业务合同，因此删除实际没有实现的入口。预检/报告沿用已存在的数据集选择链，不重新暴露路由已退出的旧审计视图。

## Consequences

目录更新和失败会被同一资源的多个观察者看到，调用方必须按当前表单/视图决定何时反馈；关闭的生成弹窗已有相应回归。局部草稿与选择不从目录响应重新初始化。查询取消只结束失效读取与发布，不回滚已提交的后端动作。

认证 Fetch 单元用例不启用跨标签页通道，避免 Node 线程通道参与本不测试的窗口同步；专门的认证存储同步用例继续保留。真实浏览器验证使用受控接口，覆盖历史继续对话、移动端长错误与键盘重试、空闲任务的身份失效，以及原有公开就绪和任务刷新错误；不等于真实后端联调。

具体命令、原文依据、代码范围、命名记录与未完成范围在 .frontend-structure/20261112-full-frontend-guidelines/ 中。哈希与清单核验只说明记录对应当前代码，不能替代语义审查；整个前端目标仍包含未审查文件。

命令切片的独立只读复核发现过错误目标：入库操作没有预检，执行监控没有数据集报告入口。当前命令使用真实数据集选择链；源码复核和浏览器导航分别记录在 global-components/ 中。仅凭菜单 push 被调用不能证明后续业务可达。

本记录与[知识库与文档详情的类型和值归属](../simplification/2026-11-05-knowledge-document-workspace-owned-values.md)部分关联：目录查询持有者变化，其选择和未提交草稿保留合同继续有效，不替代原决定。活跃笔记检索未发现相同的消息缓存形状、任务中心访问或目录投影决定。
