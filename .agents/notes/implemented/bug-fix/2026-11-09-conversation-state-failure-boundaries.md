# Agent Note: 对话范围与后台状态保留真实失败

Status: implemented

## Problem

对话访问检查把全部已删除的文档 ID 提交为空数组，聊天范围解析随后把它当作开放／数据集范围。解析器本来有“文档已不可用，重新选择范围”的 409，但访问检查提前清空 ID，使该分支无法保留原始选择意图。

结构化记忆持久化与历史上下文读取又用 or 20／or 8 覆盖真实零预算，虽然提取器与上下文构造器已经明确处理零上限。将某类记忆上限设置为零不能按其原有契约停止提取或裁剪已有记忆。

流式写入的工作线程把所有异常转成 False，外层随后正常返回，已有任务完成回调无法看到主写入失败。调度和可选摘要又叠加 suppress；任务调度失败没有日志，完成回调格式化原始异常，可能携带数据库绑定的聊天内容。

## Decision

仅在至少有一个文档仍存在时，访问检查才按原规则清理部分缺失 ID 并提交。全部缺失时保留原明确文档范围，不把它持久化成空数组；后续聊天解析继续使用已有 409。历史记录等访问者仍沿原返回协议取得可读列表，不新设标志、状态表或请求字段。

所有者优先级、旧 user_id 兼容、数据集和文档 ACL、部分权限的筛选、部分缺失的更新时间保护／commit／refresh 保持。用户明确选择新文档或数据集的入口继续先于旧范围解析处理，主动清除范围仍由原明确编辑操作持有。

记忆持久化及历史上下文直接向已有提取器／构造器传入 Settings 声明的原生整数。20／8 默认值只由配置持有；实体与事实预算分别尊重零，整体开关、原上下界、PII 过滤、输入顺序、消息和审计结构保持。读取历史的 lookback 与字符截断规则不属于这两个预算，不在本次调整。

流式主写入不再转成布尔结果；Session 在工作线程的 finally 关闭，执行或清理异常由已有 Task 完成回调观察。分发器直接调用同一已知调度入口，不再包第二层 suppress；不在失败后换成同步写入或重复提交。SSE 完成、缓存、消息／审计／会话写入顺序、后台选项及 to_thread 时点保持。

API 调度入口继续保留原 best-effort 约定，创建任务失败先 warning、关闭尚未交付的 coroutine，再按原协议返回；关闭失败直接传播。成功任务仍加入强引用集合并注册回调，回调先移除引用，已取消任务保持静默，其他错误只记录类型。可选摘要调度、执行、清理及结构化记忆提取分别由实际入口 warning，不影响主写入；摘要关闭错误单独记录，保留原取消传播。新增日志实参只含固定上下文标签、租户／会话标识或异常类型，不传原异常文本、堆栈、问题／回答或引用；全局日志上下文仍有原所有者。

## Alternatives considered

- 继续清空全部缺失 ID 能清理旧引用，但会把原先受限的查询变成另一个范围，且重试无法知道先前范围已失效。
- 新增 expired 状态可以单独表达失效，但需要迁移、写入和接口协议；保留已有非空 ID 即可让现有解析器处理。
- 在访问检查对全部缺失直接抛 409 可以立即失败，但会连带阻止原本允许的历史读取，因此只保留选择意图，由聊天范围入口判断是否能发起检索。
- 后台函数吞错并返回 False 能保持任务表面完成，但会绕过既有异常回调。直接交给任务入口可以利用真实 Task 状态，不增加另一个状态存储或补偿写入。
- 将任务创建失败抛回全部调用者可统一失败形式，但当前入口明确采用 best-effort 且流式 done 已先发送；保留该策略并记录失败，清理异常不再掩盖。

## Consequences

全部失效的范围会要求用户重新选择，不能无声扩大检索。旧 UUID 会保留到明确编辑操作，使用者需要区分明确未设范围和已有范围已失效；部分失效仍按原规则清理。

零预算可单独停止对应记忆提取，其他合法整数沿用原处理；不改变另一类预算或补造记忆。原提取器已经定义的空结果继续以原记录结构保存。

后台主写入失败会成为失败 Task，并由注册完成回调记录；SSE done 仍表达原生成完成时点，不能据此声称数据库已经提交。可选摘要继续独立降级并有日志。取消不被改成重试／shield；主线程已取消时工作线程仍沿原 to_thread 资源策略完成，不在本批增加新的取消协议。

既有[聊天类型与实际所有者](../simplification/2026-11-03-chat-runtime-typed-contracts.md)继续持有输入和转发归属，本篇持有范围失效与后台失败的行为约定；早期正常路径静态证据不替代本篇错误政策。

核对真实 Conversation 模型、加载／访问／范围解析顺序、现有 409 与明确范围覆盖分支。完整模块 AST 对照仅允许清理条件及其说明改变，所有 SQL、权限和正常返回保持；限定 Ruff／格式、Python 3.11 AST／源码编译与 Note 门禁提供静态证据。按用户要求未新增、修改或运行 Python 测试，未执行范围解析、检索、历史读取、SQL 或请求，静态证据不证明端到端表现。

记忆预算增量核对 Settings 两个整数默认、提取器非正上限的首个空返回及历史上下文的实体／事实切片；完整模块对照仅允许两端参数直接传值，消息／审计／事务和其他预算保持。未执行提取器、上下文构造、业务函数或 Python 测试，静态结果不证明实际记忆内容。

后台增量核对三个实际分发路径、唯一 Task 调度入口、完成回调、Session owner 和共享写入函数；完整工作树／暂存候选 AST 分别限制失败转发、已有可选边界和日志实参，其他 API 草稿保持。实际会话解析先创建／加载 Conversation 并 flush，持久化仍使用原 ID，不新增虚构会话或持久化状态。未执行 Task、coroutine、Session、缓存、摘要、消息写入或 Python 测试。
