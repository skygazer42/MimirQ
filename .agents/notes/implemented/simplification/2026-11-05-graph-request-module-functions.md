# Agent Note: 图请求由原模块的具名函数持有

Status: implemented

## Problem

GraphService 只有静态方法，没有实例状态、构造或资源生命周期。两个图页面 Hook 与数据集工作台通过类名调用请求，全仓没有构造、继承、注册、namespace、类型或 mock 依赖；searchNodes 也没有调用方，实际搜索直接使用 kgApi。

## Decision

原模块导出 fetchInitialGraph 和 expandGraphNode，三个既有消费者直接导入对应操作。两个请求共享原本重复的 options 类型。无调用的 searchNodes 包装与只转发 structuredClone 的私有函数退出，不保留兼容转发类。

功能开关查询、原始节点／边字段检查、UUID 扩展限制、请求范围与预算、嵌套克隆、原有空图失败结果和空初始图的 200 ms 过渡延迟继续由这些函数按原顺序执行。真实搜索仍使用原 kgApi 方法。图的并查集与事件总线拥有实际可变状态，继续保留类；GraphML、坐标与渲染元数据的原始边界不被类型声明替代。

图连线排序直接读取现有 primitive-text 转换结果，来源提示直接调用同一所有者。GraphML 中只有注释的随机颜色空分支退出，真实 XML 解析和未知 data 字段保留。

## Alternatives considered

保留静态类可以减少三个消费者的导入改动，但没有实际对象契约支持这一层。导出同名对象或兼容类能保留调用拼写，却继续添加命名空间包装，因此直接迁移已确认的所有消费者。把 KG 请求和 UI 状态重建为统一 manager 会涉及生命周期与请求归属，本次没有这种必要。

## Consequences

消费者可以直接定位请求函数，options 与行为没有第二个转发层。内部无调用的搜索包装退出；该模块不是对外软件包入口，调用清单保存在本批证据中。三个既有消费者仅迁移必要 import 与限定调用，完整文件审查仍按各自清单推进，本次不计入完整所有者覆盖。

与冻结源的 17 个请求场景比较核对 API 参数、调用顺序、功能开关失败、UUID 限制、深层克隆和空图／失败结果，以及唯一的 200 ms 延迟，全部相同。图连线与提示呈现另有冻结结果比较。没有启动浏览器、应用或后端。按类名与模块路径检索活跃笔记，没有同主题决定或待处理提案。
