# Agent Note: 知识库与文档详情的类型和值归属

Status: implemented

## Problem

知识库页面、文档列表和范围面板各自声明同一套标签、视图和排序取值；虚拟列表又复制框架实例方法和行字段，语义相同却有多个维护点。文档详情中的固定访问成员解析器和配置克隆包装没有可替换策略，文件夹移动对话框重复维护已有拖放路径的反馈。

三个图标样式表和状态主题表只含静态字符串，却在调用函数中重新声明。范围面板还为状态条目构造没有任何读取方的 JSX；文档列表声明了从未消费的上传回调，页面保留了同一个 setter 的旧名称转发。

## Decision

知识库的状态取值继续由已有查询模型文件持有，页面与两个面板直接消费其类型。列表属性使用真实 `Virtualizer` 的已消费方法，星云输入使用实际 Document 和 DocumentChunk DTO 的字段子集，文档发布状态直接来自 Document 字段。原生资源、组件与 SDK 的运行方式保持原样。

组件私有属性采用具名类型，并留在所属模块；React 类型明确导入，原生 DOM 事件仍使用原生声明。API 值直接绑定 barrel 实际重导出的领域对象。多态元数据仍保留其真实 unknown 边界，不用界面断言代替外部输入验证。

访问成员解析器是模块内普通函数，保留原分隔、去空、去重及 200 项上限。配置复制直接调用同一个 structuredClone；列表和卡片共用原本相同的切片入口文案处理。文件夹移动对话框复用已有移动与反馈回调，原目标校验、消息、关闭顺序和依赖保持一致。

四个静态样式表在原模块持有，所有键、值、顺序和读取方式保持。未消费的上传属性、setter 别名与未渲染的计数 JSX 被删除。真实交互布局、DOM、classes、文案和品牌资产保持。

配置的访问身份、已保存基线和编辑草稿由同一组件状态原子持有。当前访问的未提交草稿与旧基线不同时，真实数据集查询回读只更新保存基线；用户的草稿继续保留，恢复操作使用最新已保存值。切换访问仍按原规则初始化。已接受的同会话旧数据集保存继续回读、写缓存和失效查询，不通过跳过缓存更新掩盖草稿归属。

## Verification

固定基线的 26 个原始 owner、11,886 行全部全文复核；生产者和调用方按实际读取范围另记。原始测试不修改断言或输入。一次性运行时 AST、JSX、静态映射、真实 API 重导出身份及局部回调等价证明保存在外部任务证据中，行为修复以独立的 styleBase 隔离，不由归一化掩盖。

文档详情的旧切片请求覆盖新查询、以及数据集保存结果覆盖后续访问草稿的缺陷，分别有固定原始源码的真实 React DOM 红绿证据和独立修复提交。正常错误、重试、缓存回读、hash 验证和请求快照保留。文件夹移动与范围选择额外在固定修复基线和候选组件中使用相同 DOM 探针重放。

配置回归使用真实 useDatasets 和 QueryClient，覆盖旧保存经失效刷新后更新当前数据集对象的间接路径。独立审查发现的返访草稿覆盖另有原字节探针，固定缺陷源码失败后在修复上原样通过；原先仅固定数组的 Harness 不再作为这条查询链的证据。

相关 Vitest、完整非增量前端类型检查、局部 ESLint 与格式检查通过。证据边界是受控 HTTP、真实 React 状态、QueryClient 和文件夹 store；没有服务器、浏览器、真实网络、PDF/3D SDK、数据库或 Python 业务执行，也不声称视觉或真实水合验收。

## Alternatives considered

- 新建共享 model、formatter 或配置目录可以容纳这些声明，但现有查询模型、组件模块与文件夹移动回调已经持有对应职责；增加模块只会扩展导航与导出表面。
- 保留包装和重复结构能避免内部接口迁移，但真实调用方没有策略变化需求；直接消费实际所有者能减少接口漂移。
- 把请求生命周期统一成 manager、Context 或 loaded flag 可以缩短两处修复，但请求读取、已接受写入、缓存回读和局部草稿的所有权不同；各自在原组件持有具体访问与请求身份，保留真实错误边界。

## Consequences

知识库查询取值、框架方法和 DTO 字段只从实际所有者取得，私有组件契约更容易定位；重复逻辑和无读取方的中间值减少。测试需同时适配冻结基线的 barrel 与当前领域路径。静态等价与受控 DOM 证明不覆盖浏览器布局、SDK 资源释放和真实后端集成；已有可选存储、轮询、超时、排序、权限及错误策略保持。
