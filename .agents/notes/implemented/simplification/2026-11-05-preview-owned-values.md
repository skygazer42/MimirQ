# Agent Note: 预览数据与原始元数据的校验归属

Status: implemented

## Problem

预览流程重复解析已经由 ChunkPreviewItem、ChunkPreviewStats 和 LangChain Document 构造的字段；缺失字段又被默默转换成零，真实依赖难以阅读。图像流程还传递始终为真的 Pillow 可用标记，尽管模块已经直接导入 Pillow。

## Decision

已构造的预览记录直接读取字段，直方图保留字典输出并声明实际四个字段。令牌估算缺失时仍按零处理；负索引跳过、范围限制、短块和重叠阈值、排序、去重与计数规则保持。

图像处理使用现有的 Pillow 导入，退出没有外部调用的恒定能力包装与不可达的缺包分支。原始图像对象仍可来自解析器元数据，保留其实际能力检查、转换错误、资源清理和存储失败策略。

所有者 UUID 来自原始元数据和磁盘侧车文件，继续由原校验函数处理。侧车读取结果可能有 None 值，调用链用只读 Mapping 表达这个既有契约；不改侧车字段、JSON、权限或响应。缓存和锁继续保留有自身状态的类、TTL／容量默认值与互斥策略；已安装的 asyncio.Lock 构造只初始化状态，循环绑定由 asyncio 在等待锁时处理。

## Alternatives considered

统一删除所有转换和默认值能缩短代码，但会改变原始元数据、图像对象与授权边界的失败策略，因此只清理实际构造者保证的内部字段。将所有元数据改成新模型可以强化类型，却需要迁移解析器和持久化格式，当前用记录类型及既有映射即可表达所需契约。

## Consequences

主流程少一层重复解析和能力参数，统计与图像输出保持原形状。相关资产调用方仅迁移真实的可空映射注解；资产 API 和服务的既有完整审核结论继续有效，本批只复核注解及调用契约。验证限于源码、实际生产者、SDK 声明、Ruff 和 Python 3.11 语法，不新增、扩写或运行 Python 测试，不声称图像、缓存并发或端到端预览已运行。

活跃笔记检索仅命中表格预览的 LOTUS 决定，它处理另一条数据帧调用链，属于无关内容。本记录沿用共享标量转换所有者对原始元数据的边界约定，不替代该决定。
