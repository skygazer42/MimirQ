# Agent Note: 评测协议使用原生值与既有规范化所有者

Status: implemented

## Problem

确定性评测指标重复转换本地浮点数、长度和计数，季度刷新与 manifest 又重新清理已由样本规范化函数产生的固定字段。样本 schema 与 validator 各自声明同一组允许值，修改规则需要同步两份。

## Decision

指标直接使用浮点字面量、真除法、round、len 与整数累加产生的值。答案分词保留原正则；其两个分支都匹配至少一个字符，退出结果列表的非空过滤。召回指标只复用本地 gold 集合，检索结果仍先按原 top-k 截取，再去重计数。

样本规范化函数继续拥有原始输入的副本、字符串、标签、默认值与 schema。季度刷新和 manifest 直接使用其固定字段，修改标签前仍复制列表；hash seed、排序、刷新比例、数量上限和原零值策略保持。validator 从已有 schema 模块读取五组相同约束，保留原验证函数、错误与允许值，不扩大或收紧输入政策。

## Alternatives considered

保留两套约束可以让两个文件独立编辑，但同一数据协议仍会漂移，因此复用已有 schema 所有者。新建通用评测 Context 或数据管理器会增加职责层，现有模块函数已经能表达这条链，无须新增模块。

## Consequences

输入只在原规范化边界处理，指标主流程直接显示计数与计算；允许值只有一处维护。季度刷新仍产生独立的输出列表，结果字段、样本顺序、schema、哈希与数值类型保持。

验证限于完整源码、实际生产者／调用方、固定 Git 对照、Ruff、Python 3.11 AST 和静态签名／常量核对。按任务约束不新增或运行 Python 测试，不导入应用、编译或执行指标正则、数据集、模型或 SDK。源码证据不构成运行时质量验收。

活跃决定按 eval.dataset、compute_decomposition_metrics、gold_chunk_ids、quarterly_refresh 和评测协议检索；既有共享标量与图谱分桶记录属于其他边界，不被替代。
