# Agent Note: 切块预览共用已确认相同的领域计算

Status: implemented

## Problem

切块工作台、预设与侧栏复制了分隔符解码和预设映射。上下文、原文与切片列表分别判断 PDF，统计与 A/B 对比复制了相同的分位数算法。对比弹窗重复声明已有运行历史类型，导出格式化重新检查自己刚构造的固定 schema、时间、布尔值和集合计数。

原有预设对象查表还会把继承属性当成分隔符。存储或配置中的 `toString`、`constructor` 会令侧栏在格式化有效分隔符时抛错，`__proto__` 会返回对象；这三项都不是已定义的预设。

## Decision

分隔符解码和预设字符映射归入一个具体的 separators 领域模块，由三个真实消费者复用。消费者保留各自的空值策略：侧栏展示可以保留成功解码后的空串，工作台请求与预设继续使用各自已有的段落回退；未改变请求字段、策略或存储格式。

预设查表只接受映射自身定义的键，未定义的字符串使用既有段落回退。七个合法预设、解码规则和原始配置值不变；不把继承属性当作合法配置，也不在每个组件重复校验。

PDF 判断归入现有 pdf-dock 所有者，三个消费者使用同一个原始 file_type／文件名规则。分位数从现有 stats 所有者导出给 A/B 对比，保留原来的取整、边界与空数组行为。上下文和对比弹窗直接使用 ChunkPreviewState 的运行历史类型，去除只转发 generateRequestId 的回调与廉价标量的 useMemo 包装。

导出直接调用已有 primitive-text 单行转换函数，移除本模块刚构造的固定 schema、ISO 时间、布尔值、数组长度、Set 大小和已归一化范围的重复兜底。来自后端的文件、参数、统计、原始元数据、索引列表和可选字段仍保留原校验与展示策略；没有按 TypeScript 声明删除这些原始边界。

## Alternatives considered

把所有数值裁剪或所有覆盖合并逻辑都抽成通用工具，会合并并不相同的规则。例如列表对内容编辑重新估算 token，而导出保留自己的 token 与禁用字段策略；两者没有共用整个投影器。不同哈希输出或不同空值回退也没有因为名称相似而合并。

没有为压缩大组件行数拆出一次性小组件或宽泛 manager。新增分隔符模块负责已有多处消费的具体编码语义，其他能力继续复用现有领域所有者。

保留普通对象并直接查表最简短，但无法落实已有的未知预设回退。只在共享映射检查自身键即可解决这个边界，不需要增加配置迁移或修改每个调用方。

## Consequences

冻结原始 Git blob 与当前实现的三千零六十一项纯计算及结构比较通过，另有一百八十一项只读文件完整性比较，总计三千二百四十二项。输入覆盖分隔符解码与消费者回退、PDF 大小写与名称判断、长度统计、覆盖率、A/B 证据、编辑和禁用策略、CSV／Markdown／JSONL／审查报告、检索和重排；有效样本没有被捕获异常替代。

二十个现有 TSX 所有者的 JSX 标签、非事件属性和样式字面量保持一致。Provider 新增的工作区组件没有 DOM 包装。相关行为修复另由真实 DOM 用例验证；等价性脚本不执行下载、SDK、浏览器或后端。

同一份真实 Sidebar／存储回归在修复前记录三项失败和一项未知键对照通过：两个函数继承键导致渲染失败，对象继承键不符合字符串回退。检查同时核对原始存储值与具体分隔符结果，不通过改写输入或捕获渲染错误隐藏问题。

检索没有同主题决定。[工作区请求归属](../bug-fix/2026-11-05-chunk-preview-workspace-request-ownership.md)记录已复现的行为缺陷和请求快照变更；本记录解释不改变语义的职责收敛。当前没有同主题 proposed／rejected 记录。
