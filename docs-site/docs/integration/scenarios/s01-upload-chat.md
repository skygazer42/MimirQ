# 场景 — 上传后对话

## 概述

本页属于 **集成** 域的 **E2E** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

最小路径：注册/登录 → 上传 → 等状态 → chat stream。
