# 数据集 — 权限与安全

## 概述

本页属于 **数据集** 域的 **后端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

租户隔离、数据集 ACL、管理端与普通用户可见性差异；勿在客户端伪造 `X-Tenant-ID`。
