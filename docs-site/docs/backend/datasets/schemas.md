# 数据集 — 请求与响应要点

## 概述

本页属于 **数据集** 域的 **后端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

创建/更新数据集时的名称、描述、可见性、分类绑定等字段；分页列表的 `skip`/`limit` 与统一错误包格式。其余字段请直接查 `web/openapi.json` 或 Redoc。
