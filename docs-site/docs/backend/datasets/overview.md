# 数据集 — 概述与边界

## 概述

本页属于 **数据集** 域的 **后端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

说明数据集、分类、预检、画像、健康度、DB Catalog、表（TAG）等能力边界；非目标：不在此重复 OpenAPI 全量字段表。
