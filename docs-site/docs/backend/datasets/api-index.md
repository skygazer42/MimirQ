# 数据集 — API 参考索引

## 概述

本页属于 **数据集** 域的 **后端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

按 OpenAPI `tag` 对齐：在 Redoc 中筛选 **datasets** 及相关路径；关键 path 包括 `GET/POST /datasets/`、`GET /datasets/{{id}}`、`PATCH /datasets/{{id}}`、`DELETE /datasets/{{id}}` 等。
