# 数据集（前端）— 用户路径与入口

## 概述

本页属于 **数据集** 域的 **前端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

`web/app/datasets/**` 下列表、详情、预检、画像、健康、DB Catalog、表、工作流等页面；权限可见性随 RBAC 变化。
