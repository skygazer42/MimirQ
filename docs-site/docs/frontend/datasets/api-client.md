# 数据集（前端）— web/lib/api 模块

## 概述

本页属于 **数据集** 域的 **前端** 视角。权威契约以 OpenAPI（Redoc）为准；前端路由以 `web/app/**/page.tsx` 为准。

`web/lib/api/datasets.ts` 等模块中的封装函数与类型；与 OpenAPI 字段对齐方式。
