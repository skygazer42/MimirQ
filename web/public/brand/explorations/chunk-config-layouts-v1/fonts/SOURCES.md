# Ragvia UI fonts

Noto Sans SC and Manrope are self-hosted from Google Fonts, using the complete supplied unicode ranges and variable weight ranges. Browser font selection downloads only the ranges needed for the current content. These are not fixed-page glyph subsets.

- Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Retrieved: 2026-10-21
