# KB 功能优化（20 条 · 按 1→2→3→4→5 顺序）实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 围绕「可视化、文档解析、文档入库、文档治理、知识库管理」补齐关键功能闭环，让每条链路都做到 *可解释、可回溯、可运营*。

**Architecture:** 以现有 `Parse → Governance → Chunk → Index` 为主线；新增能力优先做成 **可配置（profile/policy）+ 可审计（timeline/log）+ 可视化（diff/metrics）**，避免一次性推翻架构。

**Tech Stack:** Backend: FastAPI + SQLAlchemy + Postgres. Frontend: Next.js (App Router) + Tailwind/shadcn + vitest. 解析/切块：现有 subprocess worker + chunker_factory。

---

## 参考对标（用于确定“必须能力”）

- Dify：支持文档启用/禁用、归档/取消归档、以及 chunk/分段的编辑与启用/禁用（面向运营治理闭环）。
- MaxKB：提供分段预览与编辑、分段管理与启用/禁用等（更偏“入库前/入库后”可治理）。
- RAGFlow：提供“文件管理/知识库配置/分块方法”等更完整的解析+知识库链路（适合补齐你项目的解析/入库/治理闭环）。
