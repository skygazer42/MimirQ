# Governance Rule Packs

Rule packs are optional, named governance presets that expand into additional **regex cleaning rules**.

Key properties:
- **Default OFF**: packs do nothing unless explicitly enabled.
- **Conservative**: packs are line-oriented (anchored) and aim to remove obvious low-value boilerplate.
- **Explainable**: you can preview the effect via the Clean Preview API/UI.

## How To Enable

### 1) Per-request / per-document pipeline options (API)

Use `DocumentPipelineOptions.governance_rule_packs`:

```json
{
  "pipeline": {
    "governance_rule_packs": ["web_cookie_banners", "web_navigation"]
  }
}
```

### 2) Persisted metadata (dataset/document defaults)

Rule packs are stored under:

```json
{
  "metadata": {
    "pipeline": {
      "governance": {
        "rule_packs": ["pdf_watermark"]
      }
    }
  }
}
```

### 3) Governance Profiles

Profiles can enable packs by putting `governance_rule_packs` in `payload.pipeline_patch`.

Note: built-in profile `builtin:html_web` enables:
- `web_navigation`
- `web_cookie_banners`

## Available Packs

### `web_cookie_banners`
Removes common cookie-consent banners and buttons (English), e.g.:
- `Cookie Consent`
- `We use cookies ...`
- `Accept cookies`

### `web_navigation`
Removes common navigation prompts (line-oriented), e.g.:
- `Skip to content`
- `Back to top`
- `Share this`
- breadcrumb headers like `Home / Docs / ...`

### `email_disclaimer`
Removes common email confidentiality disclaimers (line-oriented), e.g.:
- `This email ... intended ...`
- `If you are not the intended recipient ...`

### `pdf_watermark`
Removes watermark-like full-line stamps in exported PDFs:
- `DRAFT`
- `Company Confidential`
- `仅供内部使用` / `机密` / `保密`

### `confluence_jira_noise`
Removes common Confluence export noise (line-oriented), e.g.:
- `Powered by Atlassian Confluence`
- `Created by ...`
- `Last updated ...`
- `View in Confluence`

### `markdown_export_noise`
Removes common “export/convert tool” headers/footers (line-oriented), e.g.:
- `Generated by ...`
- `Exported from ...`
- `Created with ...`
- `Last updated ...`

## Notes / Safety

- Packs are best-effort heuristics. Always verify with Clean Preview before bulk ingestion.
- If you see false positives, keep the pack disabled and use a custom Governance Profile with precise regex rules instead.
