# Governance Rule Packs

Rule packs are optional, named governance presets that expand into additional **regex cleaning rules**.

Key properties:
- **Default OFF**: packs do nothing unless explicitly enabled.
- **Conservative**: packs are line-oriented (anchored) and aim to remove obvious low-value boilerplate.
- **Explainable**: you can preview the effect via the Clean Preview API/UI.

## How To Enable

### 1) Per-request / per-document pipeline options (API)

Use `DocumentPipelineOptions.governance_rule_packs`:

```json
{
  "pipeline": {
    "governance_rule_packs": ["web_cookie_banners", "web_navigation"]
  }
}
```

### 2) Persisted metadata (dataset/document defaults)

Rule packs are stored under:

```json
{
  "metadata": {
    "pipeline": {
      "governance": {
        "rule_packs": ["pdf_watermark"]
      }
    }
  }
}
```

### 3) Governance Profiles

Profiles can enable packs by putting `governance_rule_packs` in `payload.pipeline_patch`.

Note: built-in profile `builtin:html_web` enables:
- `web_navigation`
- `web_cookie_banners`

## Available Packs

Tip: the UI discovers the latest list via `GET /api/v1/governance/rule-packs`.

### `web_cookie_banners`
Removes common cookie-consent banners and buttons (English), e.g.:
- `Cookie Consent`
- `We use cookies ...`
- `Accept cookies`

### `web_navigation`
Removes common navigation prompts (line-oriented), e.g.:
- `Skip to content`
- `Back to top`
- `Share this`
- breadcrumb headers like `Home / Docs / ...`

### `chat_export_noise`
Removes common chat-export boilerplate (Slack/Teams, line-oriented), e.g.:
- `View in Slack`
- `Reply in thread`
- `Jump to message`
- standalone timestamp/date lines

### `email_disclaimer`
Removes common email confidentiality disclaimers (line-oriented), e.g.:
- `This email ... intended ...`
- `If you are not the intended recipient ...`

### `pdf_watermark`
Removes watermark-like full-line stamps in exported PDFs:
- `DRAFT`
- `Company Confidential`
- `仅供内部使用` / `机密` / `保密`

### `confluence_jira_noise`
Removes common Confluence export noise (line-oriented), e.g.:
- `Powered by Atlassian Confluence`
- `Created by ...`
- `Last updated ...`
- `View in Confluence`

### `wechat_mp_noise`
Removes common WeChat official account copy/paste noise (line-oriented), e.g.:
- `阅读原文`
- `点击上方...关注/订阅`
- `长按...识别二维码...关注`

### `pdf_header_footer_cn`
Removes common Chinese PDF page number headers/footers (conservative full-line matches), e.g.:
- `第 3 页 / 共 10 页`
- `第3页共10页`
- `第 3/10 页`

### `notion_export_noise`
Removes common Notion markdown export noise (line-oriented), e.g.:
- `Exported from Notion ...`
- `Created time ...`
- `Last edited time ...`

### `markdown_export_noise`
Removes common “export/convert tool” headers/footers (line-oriented), e.g.:
- `Generated by ...`
- `Exported from ...`
- `Created with ...`
- `Last updated ...`

### `cn_finance_report_artifacts`
Removes common A-share annual report / prospectus disclosure noise (line-oriented), e.g.:
- board / supervisor truthfulness commitments
- stock code / stock abbreviation lines
- announcement number lines

### `cn_gov_redhead_artifacts`
Removes common government redhead-document footer and routing noise (line-oriented), e.g.:
- `抄送: ...`
- `签发: ...`
- `主送: ...`
- `主题词: ...`

### `cn_medical_record_artifacts`
Removes common medical-record display fields before downstream masking (line-oriented), e.g.:
- `病案号: ...`
- `床号: ...`
- `主管医生: ...`
- `科室: ...`

### `feishu_lark_noise`
Removes common Feishu / Lark knowledge-base export noise (line-oriented), e.g.:
- `由飞书文档导出`
- `Powered by Lark`
- `最后编辑: ...`
- `协作者: ...`

## Notes / Safety

- Packs are best-effort heuristics. Always verify with Clean Preview before bulk ingestion.
- If you see false positives, keep the pack disabled and use a custom Governance Profile with precise regex rules instead.
- Highly specific business ingestion logic can still live in a pipeline plugin or tenant-owned Governance Profile.
