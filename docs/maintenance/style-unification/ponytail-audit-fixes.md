## 生效条件与保留限制

部署时需要应用新的 Redis 策略和 Helm 配置，集群必须提供支持 RWX 的存储。`noeviction` 会把内存耗尽变成可见的写入失败，需要按容量配置队列 Redis。

已经被旧实现覆盖的图片无法由代码恢复。当前版本共用的图片仍由原有整文档清理链回收，没有新增按版本自动回收机制。历史数据的 `local` 所有者没有被猜测迁移；需要另按实际账号归属处理。

并发重试仍依靠已有 worker/管线锁避免同时处理；准备窗口中仍可能创建两个新任务，不承诺恰好一次执行。硬进程退出后的解析状态恢复沿用现有取消或重置入口，没有增加租约系统。
