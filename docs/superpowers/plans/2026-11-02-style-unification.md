## 统一标准

- Python 普通业务服务用模块函数，依赖明确传参；有状态、生命周期和框架要求的类保留。
- PEP 8 + Ruff，行宽 120，类型放签名，注释主要解释业务规则、限制和原因。
- 明确业务异常交给 API、任务或 CLI 边界转换，优先复用已有异常。
- 前端组件内聚，按复用或独立职责抽 Hook 和子组件。
- 普通具名 React 组件用 export function，事件与数组回调可用箭头函数。
- TypeScript 应用对象、Props、联合类型优先 type，声明合并场景保留 interface。
- Prettier：两空格、单引号、无分号、行宽 120，JSX 属性双引号。
- ESLint 管代码规则，Prettier 管排版，不叠加整套 Google Guide。
