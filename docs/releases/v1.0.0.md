# MimirQ v1.0.0 Release Notes / 发布说明

v1.0.0 is the current stable public release.
It is the first release we recommend for new deployments, and it matches the current README and benchmark documentation.

## Snapshot / 概览

- Full-stack open source RAG knowledge base with a Chinese-first documentation surface.
- Two supported startup paths are documented: Docker-first and host-source-first.
- Dify integration is available through both External Knowledge API and HTTP node workflows.
- Retrieval now stays generic across embedding spaces and does not rely on business-specific hard-coding.
- Evidence, provenance, and regression gates are part of the release story rather than an afterthought.

## What is included / 主要内容

| Area | Release note |
| --- | --- |
| Startup | README now presents both Docker and host startup paths clearly for new users. |
| Windows bootstrap | `make init` invokes the Python bootstrap directly without passing POSIX comment lines to `cmd.exe`. |
| Dify integration | The README links the two supported integration modes and the real workflow screenshots. |
| Retrieval quality | The latest 800-question reruns are documented in the benchmark notes. |
| Provenance | Retrieval evidence is validated with strict gates and persisted audit metadata. |
| Release hygiene | A dedicated release index and a reusable retrieval-release template are now part of the docs. |

## Compatibility notes / 兼容性说明

- Changing the embedding model requires rebuilding the existing knowledge-base index.
- The core retrieval path stays domain-agnostic; region or business routing belongs in the integration layer.
- Docker Compose and host-source startup are both supported and documented.
- Windows users can run `make init`; `python scripts/init_env.py` remains the direct fallback when GNU Make is unavailable.
- The strict provenance gate is meant to fail closed when evidence is missing or malformed.
