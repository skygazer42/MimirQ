# MimirQ 品牌资产

当前 Logo 由 Image 2 生成，核心概念是“证据井”：三层知识结构向下收敛，中央路径把一条可验证证据带回系统表面。它不再使用旧版的 M/Q 字母圆环。

## 视觉规则

- 主色为午夜靛蓝、矿物蓝、氧化青绿、骨白与克制朱红。
- 小于 64px 时优先使用 Badge，不要强行展示横向字标。
- 浅色与深色背景分别使用对应字标，不要对整张 PNG 使用反色滤镜。
- 不拉伸、不旋转、不添加轨道、字母外框、发光、阴影或额外渐变。
- 后续品牌图形继续使用“证据层 / 返回路径”语义，不恢复旧 M/Q 圆环。

## Image 2 生成方向

最终提示要求：以三层开放菱形表示证据层，中央路径返回单个朱红证据块；保持艺术编辑感、强轮廓和 32px 可读性；禁止字母 M/Q、轨道、放大镜、AI 大脑、机器人、书本、树、盾牌、符文与通用星光。

## GPT-image 认证页方向

认证页标记使用“知识之井 + Q 尾笔”的独立方向：青色路径从深海井口穿出，井心保留单个朱红证据点；不使用外围方形容器，以免与认证页卡座重复嵌套。
