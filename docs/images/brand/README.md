# MimirQ 品牌资产

MimirQ 只使用一套主标记：**Golden Evidence Gate**。它由 GPT-image 生成并针对 32–80px 场景收敛，避免 README、认证页、导航栏和 PWA 出现互相矛盾的 Logo。

## 唯一规范资产

| 文件 | 用途 |
|:---|:---|
| `web/public/brand/mimirq-mark.png` | 唯一透明背景主标记；用于 README、认证页、聊天欢迎页、导航栏、PWA 与浏览器元数据 |

浅色和深色界面使用同一个透明 PNG。背景卡片、留白和尺寸可以按场景调整，但不能换成另一套图形。

## 图形含义

- **天蓝开放结构**：可观察、可替换的 RAG 流水线，不是封闭黑盒。
- **冰蓝输入切面**：进入解析、治理、召回与重排链路的候选证据。
- **金色证据核心**：经过检查并由 Golden 回归门禁守护的可信记录。
- **不对称出口**：从多路候选收敛为可追溯的引用与答案。

## 使用规则

- 主标记必须保持原始比例，不拉伸、不旋转、不描边。
- 不添加字母外框、轨道、发光、阴影或额外渐变。
- 不重新引入旧版“证据井”、分层菱形、深色 Badge 或独立横向锁定图。
- 需要字标时，在界面或文档中使用原生文本 `MimirQ` 与主标记组合，不再维护另一张带文字的 Logo 图片。
- 小尺寸下保留金色核心和开放缺口；不要裁切透明安全区。

## 生成方向

最终方向以“可检查证据、可替换阶段、版本化 Trace 与 Golden 回归门禁”为核心。图形保持天蓝主色、冰蓝输入切面和克制金色证据核心；禁止具象茶壶、井、相机光圈、扫描框、AI 大脑、机器人、数据库堆叠及通用星芒。
