> 获取系统版本和功能状态信息

## 获取元数据

```bash
GET /api/v1/meta
```

**响应：**
```json
{
  "name": "MimirQ",
  "api_version": "v1",
  "time": "2024-01-01T00:00:00Z",
  "build": {
    "sha": "abc1234",
    "time": "2024-01-01"
  },
  "features": {
    "auth_mode": "jwt",
    "vector_backend": "milvus",
    "task_queue_enabled": true
  },
  "runtime": {
    "python": "3.11.0",
    "platform": "Linux-5.15.0"
  }
}
```
