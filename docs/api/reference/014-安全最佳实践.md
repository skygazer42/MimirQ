# 安全最佳实践

## Token 安全

### 存储建议

| 存储方式 | 安全性 | 建议 |
|----------|--------|------|
| localStorage | 低 | 仅开发环境 |
| httpOnly Cookie | 高 | 生产环境推荐 |
| 内存 | 中 | 单页应用可用 |

## 输入验证

```python
# 后端已做验证，前端也应检查
def validate_input(message):
    if len(message) > 10000:
        raise ValueError("消息过长")
    return message.strip()
```

## CORS 配置

生产环境应限制允许的域名：

```python
# 后端配置示例
CORS_ORIGINS = ["https://your-domain.com"]
```
