# 系统配置 API

> **联调视角**：动态配置与权限边界常与「首日上线」环境准备相关；见手册 [首日上线](https://skygazer42.github.io/MimirQ/handbook/docs/integration/tasks/go-live-tenant)（[集成总览](https://skygazer42.github.io/MimirQ/handbook/docs/integration/welcome)）。

## 获取当前配置

```bash
GET /api/v1/settings
```

**响应包含：**
- LLM 配置
- 向量数据库配置
- RAG 参数
- 功能开关

## 功能开关

| 开关 | 说明 |
|------|------|
| `kg_enabled` | 知识图谱 |
| `docling_enabled` | Docling 解析器 |
| `mineru_enabled` | MinerU 解析器 |

## 更新配置

```bash
PUT /api/v1/settings
```

> 需要管理员权限
