# 快速参考卡片

## 最常用接口

```bash
# 登录
POST /api/v1/auth/login

# 上传文档
POST /api/v1/documents/upload

# 检查状态
GET /api/v1/documents/{id}/status

# 开始对话
POST /api/v1/chat/stream
```

## 必备请求头

```
Authorization: Bearer <token>
Content-Type: application/json
```

## 状态码速查

| 码 | 含义 | 处理方式 |
|----|------|----------|
| 200 | 成功 | 正常处理 |
| 401 | 未认证 | 重新登录 |
| 404 | 不存在 | 检查 ID |
| 502 | LLM 错误 | 检查 API Key |
