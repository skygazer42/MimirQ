# 提示词模板管理

> **联调视角**：模板变更对线上问答效果的影响，建议在 [可对用户问答](https://skygazer42.github.io/MimirQ/handbook/docs/integration/tasks/knowledge-base-qa) 流程中做回归（[集成总览](https://skygazer42.github.io/MimirQ/handbook/docs/integration/welcome)）。

## 为什么需要模板？

- 统一管理 Prompt
- 支持 A/B 测试
- 版本控制

## 创建模板

```bash
POST /api/v1/prompt-templates
```

```json
{
  "name": "客服模板",
  "content": "你是客服助手。\n\n上下文：{context}\n\n问题：{question}",
  "variables": ["context", "question"],
  "category": "chat"
}
```

## 在对话中使用模板

```json
{
  "message": "问题内容",
  "document_ids": ["doc-id"],
  "prompt_template_id": "模板UUID"
}
```

## A/B 测试

```json
{
  "prompt_ab_experiment_key": "experiment_1"
}
```
