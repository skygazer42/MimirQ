# 性能优化建议

## 前端优化

### 1. 防抖处理

```javascript
// 避免频繁请求
function debounce(fn, delay = 300) {
  let timer
  return (...args) => {
    clearTimeout(timer)
    timer = setTimeout(() => fn(...args), delay)
  }
}

const debouncedSearch = debounce(search, 500)
```
