MimirQ has been deployed.

Useful endpoints:
- Health:  /api/v1/health
- Ready:   /api/v1/health/ready
- Metrics: /metrics (requires PROMETHEUS_ENABLED=true)

Prometheus Operator:
- Set prometheus.serviceMonitor.enabled=true to create a ServiceMonitor
- Remember to also set secretEnv.PROMETHEUS_ENABLED=true so /metrics is enabled

Security / Hardening:
- Recommended securityContext defaults are enabled; set security.hardened=false only for an incompatible custom image
- By default automountServiceAccountToken=false (safer); set api/worker/cronjobs.*.automountServiceAccountToken=true if needed
- Use serviceAccount.create=true (or serviceAccount.name=...) to run pods under a dedicated ServiceAccount

NetworkPolicy (optional):
- Set networkPolicy.enabled=true to restrict ingress (api allow same-namespace by default; worker denies ingress)
- Egress is still allow-all unless networkPolicy.egress.restrict=true
- After install:
  kubectl -n {{ .Release.Namespace }} get networkpolicy | grep {{ include "mimirq.fullname" . }}

If you enabled Ingress:
  kubectl -n {{ .Release.Namespace }} get ingress {{ include "mimirq.fullname" . }}

If you did NOT enable Ingress, you can port-forward:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "mimirq.fullname" . }} 8000:{{ .Values.api.service.port }}
  curl -fsS http://localhost:8000/api/v1/health/ready
