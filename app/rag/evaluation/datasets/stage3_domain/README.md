# Stage 3 Domain Chunk Failure Set

This directory contains a small stage3 domain-oriented evaluation slice focused on
the three chunk-failure classes called out in the context-expansion plan:

- `semantic_missing`
- `semantic_ambiguity`
- `structure_loss`

Files:
- `manifest.json`: aggregate metadata for the combined stage3 domain set
- `legal.jsonl`: legal-domain semantic-missing samples
- `finance.jsonl`: finance-domain ambiguity samples
- `support.jsonl`: support / knowledge-base structure-loss samples
